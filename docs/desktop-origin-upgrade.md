# 桌面离线数据来源升级

桌面端现在将端口写入用户数据目录的 `desktop-origin.json`，后续启动保持相同 HTTP Origin。端口被占用时会明确报错，不再自动切换到看起来空白的离线数据库。

首次升级优先复用 `IndexedDB` 目录中最近使用的 `http_127.0.0.1_<port>.indexeddb.leveldb` 来源。旧版本可能留下多个来源：它们不会被删除，也不会自动跨账户合并。升级前退出应用并备份整个用户数据目录。

如需恢复其他旧来源的待同步数据：退出应用、保留备份，在 `desktop-origin.json` 中将 `port` 设为目标旧目录名称中的端口；重启并登录原账户，确认待同步项目及冲突。同步完成后退出并恢复原 `desktop-origin.json`。不能在应用运行中改端口，也不要直接拼接多个 LevelDB 目录。

自动选择来源、端口持久化和占用处理有 Node 回归测试；Windows 安装包的实际升级、断网编辑后重启仍需在目标平台验收。

## 已完成

### 1. 功能 / 体验

- 新增 `coach_action_attempts`：用户开始一条建议后得到独立关联标识，不把“打开页面”误写成“完成学习”。
- 番茄钟开始/完成/中断、复习完成和确认日计划草案会将真实领域事件回连到该标识；不可自动观察的动作保留用户明确的完成/放弃确认。
- Agent 页支持继续行动、查看回放和区分真实行为与用户确认；番茄钟、复习和计划页携带关联标识；计划草案仍须确认后才写入。
- 建议执行率新增已开始、领域事件完成、用户确认完成和放弃的分项。

### 2. 数据与降级

- Alembic `20260826_14` 新增 `coach_action_attempts` 及 `pomodoros.coach_action_attempt_id`；现有 SQLite 由 lightweight migration 加法兼容。
- 过期建议只标记为过期，不计为负反馈；自动归因失败时不伪造完成，可让用户明确确认结果。
- 回放只保存 nudge/尝试标识与最小事件字段，不复制建议正文或自由文本到公共事件账本。

### 3. AgentRuntime v0 与周报草案

- 复用既有 AgentKernel、Coach 偏好、策略学习和回放契约，新增 PostgreSQL 服务端低频 worker；只有用户明确开启“定时评估”才会进入扫描。
- 首个主动场景固定为“复习积压”：建议只进入 Agent 面板，仍受每日上限、冷却、稍后提醒和“太打扰”反馈控制，不会自动开始番茄钟、修改计划或创建任务。
- Agent 页新增“本周复盘”：从学习事件、北极星指标和当前任务/复习状态生成可读草案，提供最多三条跳转式下一步，不写入用户计划或任务。

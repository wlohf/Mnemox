# 更新记录：知识巩固周报来源追溯与只读草案

## 本周期目标

- 把已有“本周复盘”升级成可核对来源、稳定去重、可审阅复制的知识巩固草案。
- 在任何自动写回前先固定用户隔离、自然周、Obsidian 所有权和回滚边界。

## 指标与范围

- 对应北极星指标：间接支持复习按时率与每周有效学习时段数；本切片不宣称行为改善。
- 本周期范围：当前用户的当周笔记、已完成复习、错题线索与 Markdown 导出。
- 明确不做：自动创建笔记、修改计划、写回 Obsidian、夜间定时生成、资料/概念/时态记忆四层摘要。

## 已完成

### 1. 本地自然周与来源追溯

- 根据经校验的 IANA 时区，将本地周一 00:00 到下周一 00:00 转为 UTC 半开自然周；即时报告扫描至生成时刻（含），并同时返回本地日期、UTC 边界和端点语义。
- 笔记按最近更新、复习按完成时间、错题按最近出错时间扫描；所有查询强制当前用户隔离，每类最多取最近 8 条。
- 排除上周、未来、其他用户和 vault `missing` 笔记；来源附类型、领域 ID、时间、页面路由和不超过 160 字的摘录。

### 2. 稳定草案键与所有权

- 笔记来源引用覆盖标题/正文内容指纹；复习与错题引用覆盖影响摘要的关键字段。来源版本、复盘结论和下一步共同生成 SHA-256 内容哈希与稳定草案键。
- 同一用户、时区、时间点和证据会生成相同键与相同 Markdown；来源内容变化会生成新键，便于未来幂等保存而不误覆盖旧草案。
- 本地笔记标记 `mnemox`，导入笔记标记 `obsidian_read_only`，冲突笔记标记 `obsidian_conflict`；导入和冲突来源都只允许读取。

### 3. 真正只读的生成链路

- 周报调用学习快照时显式关闭用户画像加载，修正了 GET 报告可能隐式计算并提交 `user_profiles` 的旧行为。
- 返回 `write_policy.mode=copy_only`、`automatic_write=false` 和 `obsidian_write_allowed=false`；本模块不新增表、事件或写入端点。
- Agent 页显示周期、来源计数、最多三条摘录、截断提示和 Obsidian 只读提示；用户可主动复制完整 Markdown。

## 失败、降级与数据变更

- 无可用来源时仍返回结构完整的空证据草案和默认最小行动。
- 剪贴板权限不可用时只显示错误提示，不尝试其他写入通道。
- 本模块不新增 schema 或迁移；生成没有持久化副作用，关闭或丢弃草案即可回滚。

- 当前来源只覆盖笔记、已完成复习和错题线索；下一切片应通过既有四层接口补资料证据、已确认概念关系、时态记忆和学习状态，避免直接拼接底层表。

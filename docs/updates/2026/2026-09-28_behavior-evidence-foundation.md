# 动态用户理解：首批专注证据基础

## 本次交付

落实 DI-0 的首批可用流程：记录番茄钟 → 形成可追溯的当前证据 → 在学习画像、今日统计、Coach 快照及聊天查询中使用。阶段状态见[路线图](../../roadmap.md)，本次未实现开放行为假设或 Graphiti episode 连续辅导。

- `Pomodoro` 分开保存计划时长、明确报告的实际时长与记录来源。历史不明时长保持未知；中断前明确记录的实际学习可以计入。未提交实际值的结束事件不再把计划值写作实际耗时。
- 旧离线批量记录未提供计划时长时保持空值；缺少开始时间的兼容估算标记为 `offline_estimated`，证据返回 `estimated_start_time` 且不把估算值当作已知开始时间或独立的时长校验依据。
- 新增 `BehaviorEvidenceService` 和只读 `/api/profile/evidence`，提供规范来源 ID/内容指纹、发生/记录时间、用户自然日、来源分组、任务上下文、缺失和质量说明。事件接收时间由服务器写入 `metadata.recorded_at`。
- 汇总只从规范 Pomodoro 读取一次，开始/结束事件和派生报告不重复增加时长。相同 StudySession 的记录共享经历组；组数不自动等于独立样本量。
- Demo/模拟、未结束、时间基础未知、未来/倒序与冲突结果退出汇总。长时记录保留并提示复查；实际时长超过可信经过时间则不计入分钟。最多读 5,000 条并显式说明截断，不默默冒充完整历史。
- 画像、今日统计、Coach 与聊天专注数据使用用户时区。画像跨自然日、时区变化及旧契约时重算；普通缓存仍可显式刷新。日历边界覆盖夏令时。
- 画像页展示完成占比、时长记录完整度和任务关联占比，未知显示为未知。修正旧分数重复乘 100 和时段字段不匹配；只调整数据绑定与含义，没有重做样式。
- 画像提示与聊天查询不再提供旧能力评分；Agent 准备度不再使用这些评分或记忆数量。EDA 不再按记录量硬分人格类型、伪造 62%～96% 置信度或据此指定“最适合”的任务时段。EDA `profile.confidence` / `summary.profile_confidence` 现为 `null`，前端类型与显示同步调整。
- 新增[评测案例格式](../../evaluation/dynamic-understanding-case-template.md)，分开发现输入、后续验证、来源修订、结果、质量与成本；没有引入独立情感模型或新的调度框架。

## 迁移与兼容

新增 Alembic `20260928_29`（前置 `20260925_28`），以及 SQLite 轻量迁移。新增 `planned_duration` / `actual_duration` 可空，`record_origin` 默认 `legacy`；不猜测历史实际值，不修改历史时间。旧 Demo 仅在账号含生成器标记且记录备注精确匹配时按演示来源处理，原数据不删除。

正常升级继续使用后端既有 `python run_migrations.py` 入口。此次只在临时数据库演练，没有升级真实数据库、启用图服务或部署服务。回滚新增列会丢失新采集的计划/实际区分及来源信息，正式升级/回滚使用备份恢复流程；迁移兼容测试不代表已部署。

原 `duration` 和画像数值字段为旧调用方保留；画像四个评分字段在 OpenAPI 标记 deprecated。新消费方应使用可空实际时长、缺失数量与 `evidence_summary`。详细归集、缓存和截断语义见[学习 API](../../api/learning.md)。

## 已知边界与下一步

DI-0 仍进行中。首批证据只覆盖 Pomodoro 与可验证归属的当前任务/会话上下文，复盘、Coach 行动结果尚未形成统一证据 DTO；计划内容保护、计划勾选与 Task 状态一致性仍需收口。

EDA 其他图表、旧计时统计及部分旧 Agent 规则还使用历史口径。本次移除了 EDA 的硬编码类型/置信度，并在报告说明边界，没有把全部旧分析迁成新证据服务。历史已生成记忆没有自动批量重写。

当前来源指纹随当前数据重算，不是持久修订链；任务上下文不是当时快照，不能据此声称支持历史 as-of 回放。跨午夜专注整体计入结束日，未拆分实际活跃分钟。缺失较多时，总实际分钟只代表已知部分。

后续先完善多来源证据及任务一致性，再实现 DI-1 的开放候选、支持/反例、评估修订和用户纠正入口；真实 Graphiti episode 抽取与跨会话连续辅导按 DI-2 实施。更多记录不会自动升级为确定结论。

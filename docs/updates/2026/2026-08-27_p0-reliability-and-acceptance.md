# P0 可靠性与验收收口（2026-08-27）

## 本周期目标

- 收口不应依赖人工判断的 P0 风险：离线数据冲突、检索降级可见性和关键路径验收稳定性。
- 区分“代码已保护”与“真实发布环境已留证”，避免把本地验证当成正式上线结论。

## 已完成

### 1. 离线同步冲突不再静默覆盖

- 笔记、目标和目标任务在上传前会校验云端版本是否已变化。
- 本机离线修改与云端修改同时发生时，记录会进入 `conflicted` 状态；系统不会再按时间戳直接覆盖其中一边。
- 账户菜单的同步状态会显示待处理数量，并提供“保留本机并同步”与“采用云端版本”两种明确操作。
- 云端已删除时也会保留冲突信息；只有用户选择保留本机版本，才会重新创建云端记录。

### 2. 检索降级对学习者可见

- 对话输入区会显示当前资料检索是“语义 + 关键词”还是“关键词保底”。
- 每次对话完成后都会重新读取检索健康状态，避免界面继续展示过期的可用状态。

### 3. 浏览器验收改为等待真实界面状态

- 计划生成、笔记新建和仪表盘任务断言均等待接口响应和实际页面元素，不再依赖固定等待时间。
- 笔记场景改为通过界面真实创建，不再手工伪造 IndexedDB 数据结构。
- 覆盖番茄钟、计划、笔记、侧边任务跳转、Agent 草稿确认五条关键路径。

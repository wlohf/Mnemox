# 首页学习工作台与组件动效

## 本次范围

优化 `/` 与 `/conversations/:conversationId` 共用的首页。按最新反馈改为浅白色主画布、极浅灰侧栏和黑白按钮；深色主题同步改为中性灰。参考方向为 [ChatGPT](https://chatgpt.com/) 的简洁产品界面。

## 功能与体验

- 全局 CSS 与 Ant Design 共用一套颜色变量，移除首页 Logo、同步状态、计时、任务勾选和搜索高亮的独立装饰色。用户消息改为浅灰气泡；输入框、模型选择与按钮使用统一圆角及轻阴影。
- 默认主题改为浅白，保留已有深色/跟随系统选择和本地 `warm` 兼容键；设置标签同步更新。界面约定记录在根目录 `DESIGN.md`。
- 空对话展示来自 `today_mission` 的下一步行动、推荐理由、预计时长和可展开的主动回忆提示；提供首次使用、加载与失败重试状态。
- 保留聊天输入、模型选择、图片上传、检索状态和快捷提问。快捷提问会填入输入框并交还焦点。
- 右栏组件使用统一 `FoldPanel`，默认展开今日任务，其余按需展开。各面板记住展开状态；日历继续使用原有日历偏好。
- 新用户默认显示任务、复习和专注计时，其他组件可从“自定义面板”启用。已有卡片选择、顺序与宽度偏好继续生效。
- 按钮复用 Ant Design，通过 `ActionButton` 增加按压、扫光和图标位移；React Bits ClickSpark 提供局部点击反馈。组件来源与完整许可保存在 `frontend/src/components/ui/`。
- GSAP React hook 负责首页入场；折叠使用可中途反向的 CSS grid 过渡。点击特效仅在交互时绘制，空闲或页面隐藏时停止。
- 1180px 以下侧栏按需覆盖展开，支持 Escape 关闭；窄屏操作不覆盖桌面的折叠偏好。隐藏区域使用 `inert` 隔离键盘操作。
- 适配系统减少动态效果设置。禁用或加载中的按钮不触发点击特效。
- 增加“沉浸模式”：同时收起左右侧栏和全局导航，保留居中的聊天与输入框；空对话只展示简洁提问入口。顶部按钮或 Escape 退出，恢复进入前的侧栏状态与宽度。
- 左侧栏现在能完全收起，不再保留额外的 72px 图标栏。内容保持挂载，隐藏后通过 `inert` 隔离焦点；模式切换保留聊天、草稿与侧栏内部状态。
- 沉浸偏好单独保存为 `layout_immersive`，刷新继续生效。手机进入时关闭侧栏遮罩；弹窗和下拉菜单优先处理 Escape。

## 修复

- 未保存右栏宽度时，不再将 `null` 转为 0 后压到 200px；默认使用 304px。
- 侧栏拖拽时关闭尺寸过渡，避免拖动落后于指针。
- 右栏内容保持挂载，减少重复入场和展开时的内容挤压。

## 验证方式

```bash
cd frontend
npm test
npm run lint
npm run build
MNEMOX_E2E_BASE_URL=http://127.0.0.1:5174 npm run test:e2e
MNEMOX_E2E_BASE_URL=http://127.0.0.1:5174 npm run test:e2e:home
```

首页专项检查覆盖键盘展开、反向收起、折叠状态持久化、快捷提问焦点、日历显隐、侧栏键盘隔离、手机布局、减少动态效果、主行动导航、加载失败重试与首次使用。

执行结果：28 个测试文件、98 个测试通过；build、lint、原有浏览器验收 5 组、首页专项验收 9 组均通过。首页专项另检查白色画布、黑白主按钮、悬停色、次按钮层次与禁用状态，以及完全折叠、沉浸切换、刷新恢复和菜单 Escape 优先级。沉浸截图使用合成对话验证聊天和未发送草稿在切换后保留。

浏览器使用合成学习数据并拦截 API，不写入真实学习记录。截图输出到 `frontend/output/homepage/`；设置 `MNEMOX_HOME_CAPTURE=0` 可跳过截图。前端交互验证不代表真实后端推荐质量验证。

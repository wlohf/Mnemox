# 2026-08-27 Coach 模拟回放与运维收口

## 本周期目标

- 在不伪造真人效果证据的前提下，补齐 Coach 行为链路的可重复模拟回归、用户可读指标和备份恢复演练。

## 已完成

- 新增 `evaluate_coach_behavior.py`。它只创建临时 SQLite 数据库，并通过真实事件账本模拟建议展示、真实领域完成、用户确认完成、放弃、中断恢复、复习到期和有效学习时段。
- 模拟还固定验证“复习积压”建议只能进入 Agent 面板、冷却会阻止重复触达、两次“太打扰”反馈会抑制同类主动建议。
- 模拟报告会明确标记 `synthetic_policy_and_metric_regression`：通过表示链路和策略没有回归，**不表示** Coach 已经对真人产生因果效果，也不会晋级学习者模型版本。
- Agent 页新增四项行为指标：建议执行（区分真实领域完成与用户确认）、中断恢复、复习按时和每周有效学习时段；提示只纳入已成熟观察窗口。
- AgentRuntime 在生成实际建议时写入最小成功记录；单用户评估失败只显示“稍后再次检查，未修改计划或任务”的安全提示，异常正文仍只在服务端日志中。公开 `/health` 增加不含异常正文的运行时间、轮次、建议数和失败用户数。
- 新增 `verify_postgres_backup.sh`：校验 SHA-256、将 dump 恢复到一次性临时库、检查关键表与 Alembic 版本后自动删除临时库。

## 验证

- 虚拟学习者回放的 7 项检查均通过；预期模拟指标为建议执行率 `75%`（4 条真实领域完成、2 条用户确认）、中断恢复中位数 `45` 分钟、复习按时率 `50%`、本周有效学习 `3` 次。
- 后端 Coach/指标/模拟专项回归通过；前端测试、生产构建与 lint 通过。
- 对当前 PostgreSQL dump 完成一次实际恢复演练：SHA-256 正确、恢复库含 `58` 张 public 表、版本为 `20260826_14`，临时库已自动删除。
